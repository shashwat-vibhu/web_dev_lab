# P1 – Terminal and Folder Navigation

## Aim
Create a project folder and practise terminal commands.

## Commands
```bash
cd ~/Desktop
mkdir WebProject
cd WebProject
pwd
mkdir css images js
ls
cd css
cd ..
```

## Explanation
- `cd`: change directory.
- `mkdir`: create a folder.
- `pwd`: show current path.
- `ls`: list files and folders.
- `cd ..`: move to parent folder.

## Expected structure
```text
WebProject/
├── css/
├── images/
└── js/
```
