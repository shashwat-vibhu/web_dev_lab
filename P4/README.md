# P4 – README and Version Tags

## Aim
Document a project using Markdown and create a Git version tag.

## Example README
```markdown
# My Portfolio
A personal portfolio website.

## Sections
- About
- Skills
- Projects
- Contact
```

## Commands
```bash
git add README.md
git commit -m "Add project README"
git tag -a v1.0 -m "First version"
git push origin main
git push origin v1.0
```
A tag marks a particular version of a project.
