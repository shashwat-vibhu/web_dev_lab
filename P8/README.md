# P8 – Sticky Navbar and Card Overlay

## Aim
Keep a navbar visible while scrolling and place text over an image.

## Files
- `index.html`: HTML structure.
- `style.css`: external CSS (no inline styles).

## Concepts
`position: sticky`, `relative`, `absolute` and `z-index`. 

## Run
Open `index.html` in a browser. Keep both files in this folder.
