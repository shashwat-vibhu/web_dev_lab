# P12 – Portfolio Projects Grid with Advanced CSS Grid

## Aim
Create responsive project cards and make the featured card span two columns.

## Files
- `index.html`: page structure.
- `style.css`: external stylesheet.

## Concepts
`repeat()`, `auto-fit`, `minmax()`, `grid-auto-rows`, `gap` and `grid-column`.

## Run
Open `index.html` in a browser.
