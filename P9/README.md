# P9 – Responsive Navbar and Cards with Flexbox

## Aim
Arrange navigation and cards with Flexbox and adapt the layout for small screens.

## Files
- `index.html`: HTML structure.
- `style.css`: external CSS (no inline styles).

## Concepts
`display:flex`, `justify-content`, `align-items`, `flex-wrap`, `gap` and media queries.

## Run
Open `index.html` in a browser. Keep both files in this folder.
