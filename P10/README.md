# P10 – Portfolio Header and Footer with Flexbox

## Aim
Arrange logo, navigation, main content and footer using Flexbox.

## Files
- `index.html`: HTML structure.
- `style.css`: external CSS (no inline styles).

## Concepts
`flex-direction`, `justify-content`, `align-items`, `flex-wrap` and `flex:1`. 

## Run
Open `index.html` in a browser. Keep both files in this folder.
